# Source and maintenance

Open PStack adapts pstack by Lauren Tan (GitHub repository `cursor/plugins`, directory `pstack`), under the included [MIT license](../LICENSE). Open PStack is maintained here and is not an official Cursor product.

The portable entry point combines the engineering intent of `poteto-mode`, `how`, `why`, `architect`, `interrogate`, `arena`, `swarm`, the principle skills, and the relevant playbooks. It retains evidence-led debugging, domain modeling, independent review, measured optimization, and revision-aware delivery.

This is a curated adaptation, not the full upstream catalog. It omits Cursor agent wrappers, hardcoded model tables, `/loop`, external team-kit dependencies, orchestration runtimes, and automatic external actions. It replaces mandatory fan-out and automatic PR creation with task-appropriate decisions. Specialized upstream tools and every upstream slash command are not re-exported.
