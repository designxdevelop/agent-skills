# Opening a pull request

When the user asks to open a pull request, inspect the complete diff against the correct base, check for unrelated changes and secrets, and complete required verification. Follow the repository's commit and PR conventions. Describe the problem, resulting behavior, and validation. Keep local-only work local when publishing is outside scope.

Status, repair, monitoring, and landing a pull request or stack are the `pr-babysit` skill. Read [pr-babysit](../../pr-babysit/SKILL.md) and follow that procedure. Do not reproduce it here.
