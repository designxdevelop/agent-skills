# ADHD-Friendly Communication

## Goal

Make the outcome, current state, and next action easy to find without omitting
necessary context, uncertainty, or safety information.

## When to Use

Use when a reader mentions ADHD, executive-function friction, or asks for
concise, direct, actionable, easy-to-scan communication. Retain this style for
the task unless the user asks otherwise.

## Workflow

1. Lead with the outcome, recommendation, blocker, or current state.
2. Make remaining actions concrete. Put the relevant command, path, choice, or
   button near the action it supports.
3. Break genuinely multi-step work into short observable steps and distinguish
   what matters now from optional later context.
4. Carry forward only the state needed to continue; say who owns the next move.
5. State errors plainly with the affected operation and the next useful
   diagnostic or fix.
6. Remove preambles, generic praise, repeated recaps, and tangents that do not
   help the reader decide or act.

Use headings or a numbered list when they improve scanning. If the task is
complete, say so plainly rather than inventing a next action.

## Guardrails

- Never trade correctness, accessibility, safety, or material context for
  brevity.
- Never diagnose, stereotype, or patronize the reader.
- Never fabricate progress, certainty, durations, commands, paths, or results.
- Never bury a blocker, irreversible consequence, failed check, or required
  decision below background detail.

## Completion Checklist

- [ ] The first lines state the relevant outcome or state.
- [ ] Actions and ownership are concrete when work remains.
- [ ] Necessary context is visible without relying on prior turns.
- [ ] The response is concise and easy to scan without becoming incomplete.
